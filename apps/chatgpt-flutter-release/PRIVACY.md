# Privacy policy

**Flutter Release Check for ChatGPT** by Chandra ObulaReddy.

- The app needs no account and asks for no personal information.
- ChatGPT sends the app only the text a tool needs, such as a pasted `AndroidManifest.xml`, `Info.plist`, `pubspec.yaml`, store listing text or a version number.
- That text is used only to produce the result for that request. Files are written to a temporary directory, which is deleted when the request ends. The app does not store this text, use it for analytics or share it with anyone else.
- The app does not log the text you submit. The hosting provider may keep standard infrastructure records, such as IP addresses and request times.
- Do not paste signing keys, passwords or API keys. The app does not need them.
- ChatGPT's handling of your conversation is covered by OpenAI's own privacy policy.
